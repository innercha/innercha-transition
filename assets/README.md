# Assets

Store working and approved brand assets here.

Suggested future structure:

```text
assets/
  references/
  wordmark/
  profile/
  banners/
  announcement/
  press/
```

## Asset principles

- Keep source files where practical.
- Use clear names and dates or versions.
- Preserve original photos and artwork outside destructive edits.
- Do not add assets merely to make the folder look complete.
- Confirm usage rights for fonts, photos, textures, and reference imagery.

## Minimum launch assets

- Profile image
- Wide banner
- Wordmark or consistent typographic name treatment
- Announcement visual
- Export sizes for major platforms
