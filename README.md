# Innercha Transition

This repository is the working home for the transition of Jeff's solo artist project from **SubRoot** to **Innercha**.

The goal is to preserve the history, audience, and relationships built as SubRoot while establishing Innercha as the active long-term identity for future music and creative work.

## Start here

1. Read [PROJECT.md](PROJECT.md) for the complete handoff.
2. Review [DECISIONS.md](DECISIONS.md) before revisiting settled questions.
3. Use [ROADMAP.md](ROADMAP.md) to stay focused on the current phase.
4. Develop the identity in [BRAND.md](BRAND.md).
5. Track platform-specific work in [PLATFORMS.md](PLATFORMS.md).
6. Check [SESSION_LOG.md](SESSION_LOG.md) for recent working notes.
7. Track release and label outreach in [LABELS.md](LABELS.md).

## Current focus

Phase 2: define the Innercha brand identity and platform strategy before making broad public changes.

## Guiding idea

> Consolidate the core. Preserve the history. Don't chase every loose thread.

This is a gradual evolution, not an attempt to erase SubRoot or rewrite old releases.
