# AI Collaboration Context

This repository is intended for use with Codex, Claude, ChatGPT, and other AI assistants.

## Read first

Before recommending work:

1. Read [PROJECT.md](PROJECT.md).
2. Read [DECISIONS.md](DECISIONS.md).
3. Check the current phase in [ROADMAP.md](ROADMAP.md).
4. Preserve existing decisions unless new evidence materially changes them.

## Collaboration guidelines

- Treat **Innercha as the selected long-term solo artist name**, not an unresolved naming exercise.
- Do not restart broad SubRoot-versus-Innercha comparisons unless Jeff explicitly asks.
- Preserve SubRoot as visible history; do not suggest scrubbing or rewriting the past.
- Prefer gradual, reversible transitions over disruptive account recreation.
- Keep recommendations proportional to the actual audience and catalog.
- Avoid expanding this into an elaborate engineering project.
- Distinguish research/planning from public execution.
- Flag irreversible actions, handle transfers, catalog metadata changes, and account deletions before they occur.
- State uncertainty when platform behavior is not guaranteed.
- Do not assume Spotify for Artists private analytics are available from Spotify's public API.
- Help Jeff keep making music; documentation should support action, not become procrastination.

## Communication style

- Be candid and supportive without manufacturing validation.
- Lead with the recommendation or outcome.
- Give concrete next actions.
- Avoid repeatedly re-litigating settled emotional reasoning.
- When offering a new idea, explain how it supports the design principles in PROJECT.md.

## Important context about Jeff

- Jeff is technically capable and appreciates structured migrations and clear documentation.
- He can also hyper-focus on details, so actively watch for diminishing returns.
- His established Instagram is hybrid personal/artist but primarily music-facing.
- His studio work is a strength; networking works best through warm relationships and small repeatable habits.
- Innercha should not be expected to solve all career momentum by itself. Music, releases, performance, relationships, and consistency remain central.

## Security

Never request or commit passwords, private API keys, OAuth tokens, or unredacted private analytics. Refer to `.env.example` for safe variable names.
